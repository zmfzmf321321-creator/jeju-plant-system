# 계측기 교체주기 자동 판별

사용자가 제공한 ‘계측기 교체주기’ 사진의 고정 연수를 기준으로 합니다.
분류 목록에서 선택한 타입을 우선 적용합니다. 목록 끝의 ‘기타’를 선택하면
분류명을 직접 입력하며 수명도 직접 적습니다. 분류가 없는 CSV 행에 한해
품명, 규격, 모델명 순으로 타입을 찾습니다.

| 타입 | 자동 입력 수명 |
| --- | --- |
| PLC | 8년 |
| 서버 컴퓨터 | 6년 |
| 운전원용 컴퓨터 | 6년 |
| LCD 모니터 | 6년 |
| LVDT | 10년 |
| 포지셔너 (RVDT) | 6년 |
| 릴레이 | 6년 |
| 로드셀 | 15년 |

제어카드, 제어카드 I/O, GPS 수신기, 네트워크 스위치는 사진에
‘제작사 Life Cycle 적용’으로 적혀 있어 고정 연수를 자동 입력하지 않습니다.
전송기·스위치·솔레노이드·서보 밸브 항목도 괄호 안 적용 조건 또는
사용 조건에 따른 주기가 있어 수동 입력 대상으로 둡니다.

등록·수정 화면에서는 자동 입력값을 직접 바꿀 수 있습니다. 직접 입력한 값은
품명 등을 바꿔도 유지되며, ‘자동값 사용’을 누르면 판별값으로 돌아갑니다.
Supabase CSV 가져오기에서는 `service_life`가 빈 행만 자동 판별하고,
CSV에 입력한 값은 덮어쓰지 않습니다.
